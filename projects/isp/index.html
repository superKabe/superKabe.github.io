What is happening

Six stages, with the math left visible.

  1. Read rawnp.fromfile reshapes a binary sensor dump into a 4096 × 2160 Bayer array.
  2. Demosaiccv2.cvtColor reconstructs RGB. The browser uses bilinear RGGB interpolation.
  3. Color + gammaA fixed 3 × 3 color correction matrix is followed by a 1/2.2 display curve.
  4. DenoiseThe notebook uses cv2.bilateralFilter. This port uses a tighter luminance-guided bilateral pass to protect detail.
  5. SharpenThe original Laplacian experiment is represented here by a controlled unsharp mask.
  6. Contrastskimage.exposure.rescale_intensity maps the useful 30 to 240 range across the output.

Original build

A notebook first, then a browser port.

I completed the original project in 2023 as a Jupyter notebook using Python, NumPy, OpenCV, scikit-image, SciPy, and Matplotlib. This was before generative AI coding tools became part of my workflow, so it is a useful snapshot of how I learned the pipeline: implement a stage, inspect the output, and tune the tradeoffs by hand.

The page you are using is a separate implementation. It keeps the same raw frame, Bayer pattern, color matrix, gamma curve, and contrast range, but rewrites the processing in dependency-free JavaScript with typed arrays.

How the browser version works

The main page never does the heavy lifting.

  1. 01

    The worker fetches the raw binary file and validates the expected 4096 × 2160 byte count.

  2. 02

    It averages same-color samples within Bayer blocks to reach 1024 × 540 without corrupting the RGGB pattern.

  3. 03

    Each stage runs on typed arrays away from the main interface thread.

  4. 04

    The worker transfers six RGBA buffers back for instant stage switching.

Why this project matters

It shows what happens before a model sees an image.

Computer vision starts with the quality and meaning of its pixels. Building an ISP from a sensor dump demonstrates practical understanding of image representation, color reconstruction, numerical processing, and the tradeoff between noise reduction and retained detail.

Porting it from a notebook to a static website also shows a different skill: translating an experiment into an interactive tool while working within browser performance and memory limits.
