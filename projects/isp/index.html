Project notes

Implementation

Original build

Completed in 2023 as a Jupyter notebook using Python, NumPy, OpenCV, scikit-image, SciPy, and Matplotlib, before generative AI coding tools were part of my workflow.

Open the notebook ↗

Browser port

The static page fetches the 8.4 MB raw frame, performs Bayer-aware downsampling, and runs each stage on typed arrays in a Web Worker so the interface stays responsive.

What it demonstrates

The project covers raw image representation, color reconstruction, filter tradeoffs, and translating a notebook experiment into a performant interactive tool.
