The pipeline

Every stage solves a different problem.

Camera sensors do not produce finished photographs. The captured values need to be reconstructed, calibrated, and refined in a deliberate order. The browser version will expose that sequence rather than hide it behind a single “process” button.

  1. 01

    Reconstruct color

    Interpolate missing color channels from the RGGB Bayer mosaic.

  2. 02

    Correct the response

    Apply a color correction matrix and gamma curve for a natural display response.

  3. 03

    Control noise

    Reduce sensor noise while protecting the edges and structures used downstream.

  4. 04

    Recover detail

    Sharpen edges and improve local contrast to create the final usable image.
