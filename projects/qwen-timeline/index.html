Experiment notes

Method and limits

Evaluation

I sampled 70 frames at 1 FPS, supplied a fixed action vocabulary, and required structured JSON intervals. Predictions match one-to-one only when the labels agree and temporal IoU reaches 0.30.

What this shows

A VLM can recognize the overall workflow while producing a timeline that is not trustworthy enough for quality, safety, or incident audit. Sampling, validation, failure handling, and human review remain part of the system.

Reference

Glossary

VLM
A vision-language model that reasons across images or video and text.
Qwen3-VL
Alibaba’s open-weight vision-language model family used for both runs.
4B / 8B
Approximate parameter counts: four billion and eight billion model parameters.
BF16
A 16-bit floating-point format used for the 4B model weights and compute.
INT8 / FP16
The 8B run used 8-bit weights with 16-bit floating-point compute to fit local GPU memory.
Temporal IoU
The overlap between predicted and reference time intervals divided by their combined duration.
1 FPS
One sampled frame per second, giving the model 70 frames from the 70-second clip.
Precision / recall / F1
Precision measures correct predictions, recall measures recovered reference events, and F1 balances both.
Boundary error
The absolute timing error at the start and end of matched events.
